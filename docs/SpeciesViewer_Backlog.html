Working task list for the SpeciesViewer nature-photo pipeline and GUI. Items are grouped by feature area. Each section shows what is open, what has been shipped recently, and what is deliberately deferred.

Still open

    Marquee-select multiple picture cards, then stamp them all with one species keyword (type-ahead auto-complete, GBIF online fallback). The current workflow handles one picture at a time; this is the batch equivalent for day-wide or trip-wide assignment.
  • Cancel button during copy NEEDS LIVE TEST
    Shipped (e6f49a7): Close becomes "Cancel" during a running copy; clicking it stops the worker. Has not yet been tested against a real SD-card copy run.

Deferred (GPS / geolocation fine-tuning)

  • Tune Nominatim zoom level so Location returns a reserve or lake name rather than the nearest road (zoom 14 currently returns roads most of the time).
  • Expose lang / radius / zoom settings and an overwrite toggle in the UI.
  • Push the Municipality field into the pipeline CSV and website output.
  • Offline reverse_geocoder (scipy) fallback for use without internet.
  • Cache the LOCATION read per navigation step if laggy.

2. Virtual Trips CORE SHIPPED

The full virtual-trip pipeline is in place and live on the website (Tucson 2023 trip). svv1 → svv5 all working; blog and website publishing fully operational; GUI panel improvements complete as of June 2026.

What was built (all shipped)

  • svv1 creates directory tree; svv2 extracts per-day CSVs from master
  • svv3 WriteBlog: auto-generates blog ini per day, uploads NL+EN blogs + sliders. Enhancements: XMP:Location sublocation in day titles; richer auto-generated message text (opening variety, species callouts with italic scientific names, quiet-day mode, (auto-tekst) marker); minimum score read from config key.
  • svv4 BuildWebsite: species HTML pages, biota tree, summaries; empty kingdom stubs for classification nodes with no trip pictures.
  • svv5 AddToMaster: registers trip in master trip_admin.csv, uploads trip picture/banner and tripindex NL+EN; live web copy fetched to avoid SmallBoy serving stale drafts.
  • Per-day blog editor (VirtTripBlogEditorDialog): tabbed QDialog, one tab per day ini; NL/EN title+message fields; ↓/↑ translate buttons; min-score + column-width spinners; Save All / Save All & Re-upload. Double-click BLOG_COL opens at that day.
  • Repositories Browse buttons default to the correct root directories.
  • VirtTripInfoPanel: ✅/📝/⚪ state icons; purple ▶ active marker; rebuilds after Create/Select; web root always derived from trip_name on trip switch.
  • TripInfoPanel: matching purple ▶ active marker; tab auto-focuses on trip click.
  • Active Trip field warning when path is inside the virttrips root.
  • bloglib.py breadcrumb links use Trip.web_prefix (not hardcoded /trips/).

Still open

  • Single-day re-upload MINOR / FUTURE
    "Save All & Re-upload All" in the blog editor re-runs the full Write-All-Blogs dialog. A future refinement could re-run svv3 for just the edited day to avoid re-processing unchanged days.
Data quality note (Tucson 2023, 2023-04-02): All pictures are ORF+XMP only — no JPG was ever exported. SmallMaster shows "(no image)" for these because it only holds JPGs. Ratings come from XMP sidecar metadata. May warrant exporting JPGs from originals and re-promoting to master.

3. Master Database & Editing

Phases 1–3 are SHIPPED & LIVE-TESTED: Phase 1 (global JSON EXIF cache under master/metadata/cache/), Phase 2 (SQLite DB-first re-rating: WAL + debounced CSV checkpoint + crash recovery + Read-Only toggle + Database dialog), Phase 3 (add / delete pictures with reversible file-move to .trash/; trash manifest; JPG-protection invariant; species-count maintenance in DB). The Rating Editor's Trip+Master scope is fully working.

Still open

  • "Undo last delete" UI button — the headless capability (undo_delete()) is built and tested; it reads the trash manifest, moves files back, and restores DB rows. No menu item or button exists yet.
  • EXIF-cache mutable bucket prune — the mutable bucket (XMP / JPG files keyed by path + mtime) grows without bound as master re-reads accumulate. Add a size-capped or time-based eviction pass.

Deferred

  • Trip-side SQLite DBs — same pattern as the master DB, not urgent now that the design is proven by the master implementation.

5. SmallMaster (Laptop-Friendly Master) COMPLETE ✓

Full feature shipped and live-tested on SmallBoy (2026-06-13). BigBoy creates smallmaster.zip (JPGs stored, text deflated, CSV paths relativized); SmallBoy installs via "Install Small Master" dialog (summary → extract → speciescollection merge → DB rebuild with absolute paths). Install dialog automatically writes readonly = yes + readonly_locked = yes to the machine config; the Repository Settings checkbox is greyed out and locked on SmallBoy. No open items.

6. Taxonomy & Species

All four items are still pending:

  • Sequence redesign — replace the "040 passeriformes" text-prefix sort with an eBird TAXON_ORDER float column. Schema change touching the species tree and all sort / display logic. Branch: seq-decouple-prefix (not started).
  • Auto-detect obscure flag — derive from GBIF family membership (Orchidaceae, Orobanchaceae, etc.) using data already fetched during species lookup. No extra API call needed.
  • Placeholder-species cleanup — ? <name> entries are intentional placeholders that propagate from trip to master via merge. Cleaning them up requires coordinated changes in both trip and master collections.
  • Regional most-likely-birds list (eBird API) — weighted auto-complete for species assignment in the culling viewer. Deferred.

7. Rating & Website

  • Rating-formula tuning DEFERRED
    Fine-tuning the weights (Red/Yellow/Green boost, star / size / DxO / description balance) is deliberately deferred to the end of the viewer-convergence work. This formula directly feeds the website best-pick selection.
  • HEIC / PNG sidecar capture NEEDS DECISION
    HEIC-only and PNG-only pictures have no writable sidecar, so rating and colour cannot be stored durably (controls are greyed in the UI today). Three options under consideration:
    • (a) Write a separate .xmp sidecar alongside the HEIC
    • (b) Patch the .dop DxO project file
    • (c) Write directly into the HEIC container
    User decision required before coding starts.

9. Usability & Polish

  • Virtual-trip preview path — needs live test PENDING TEST
    FileListPreviewCollection and FilePreviewItem back the virtual-trip file_list mode and metadata-less day folders. Import-verified but not yet exercised in a running app — confirm thumbnails render and filter buttons are greyed correctly.
  • Preview cards don't resize live
    Card width is fixed at build time and only recomputed when the column spinner changes. If this feels wrong in daily use, add a debounced resizeEvent that rebuilds at the new card width.
  • "Undo last delete" UI button — headless capability done (see item 3); surface it as a menu item or button in the Rating Editor or Database Settings dialog.
  • Watch point — Translation: when a source text is edited its CRC changes and the old cache entry becomes an orphan (stale entries accumulate, no crash). Also: if a HEIC holds a competing Headline/Description, the pipeline could re-resolve to the stale HEIC text after a re-read (not observed in testing; watch only).
  • Deferred: user-configurable cache locations (all currently in %LOCALAPPDATA%).

10. Cross-platform (Mac) Prep

First pass DONE (8701821): open_path() helper routes to the correct OS call; Windows-only defaults in dialogs cleared.

Full portability sweep still pending before the MacBook switch:

  • Remaining os.startfile() call sites — no equivalent on macOS.
  • Hardcoded paths with drive letters (E:/Dropbox/…) or backslashes.
  • QSettings registry usage — macOS uses ~/Library/Preferences.
  • Case-sensitivity traps — lookups that work on Windows NTFS but fail on macOS HFS+, e.g. file.jpg vs file.JPG.
  • subprocess calls assuming Windows paths or Windows-only tools (exiftool.exe etc.).
