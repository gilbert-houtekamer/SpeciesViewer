Species card — one look, a fixed set per viewer

The card design is shared, but we fix two things per viewer, not the user: the label style (read-only browsing = olive frame + corner dot; anything that edits name/rating/colour = full frame) and the corner info set. Only the colour scheme and theme are shared global choices. This panel is our tool for defining each viewer's set — pick a viewer to load its set.

The rule for label style. A viewer you only browse keeps the calm olive frame with the colour as a small corner dot. A viewer where you change the picture — rate it, label it, rename — switches to the full colour frame so the label reads across the whole grid, and the clickable star + colour rows appear below. (The full-frame “Tech Panel” treatment still wants a nicer look — parked for now.)

Corners are per viewer, fixed by us. Biota ships with empty corners. Species leans on format · date · Rate with the lock glyph on committed days. Strips stay sparse; the image viewer can afford camera + more. These are starting points to iterate here — they are not exposed to the user.
