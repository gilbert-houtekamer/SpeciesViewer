# Plans

Design plans, one file per piece of work: what the problem is, what was decided
and why, and the work packages. Committed so they are available on whichever
machine the work continues on.

A plan lives here from the moment it is written until the work ships. When it
ships, the outcome goes to `SpeciesViewer_Backlog.html` (what it does, in user
terms) and the durable detail to the reference docs — the plan then stays as the
record of *why* it was built that way.

Each file states its own status at the top.
